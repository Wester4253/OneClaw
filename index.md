<h1 align="center">OneClaw</h1>
<h2 align="center">Open source agentic AI for every<em>one</em></h2>

---
<h2>Why?</h2>

I found the original [PokeClaw](https://github.com/agents-io/PokeClaw) on Github a while ago, installed it, and found it quite lacking in features. i decided to clone the source code and make some modifications. over time, it shifted from my own mod of the app to being a different app. i want to upload it here so you can download it too, and request more features.

---
<h2>How do i install this?</h2>

Download the .apk from the repo, sideload or install it on your android device. The apk will be located in the latest release.
